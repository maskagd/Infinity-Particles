Infinity Particles **adds multipliers** for particles

It lets you adjust how **particles behave** by changing:
- particle count and emission rate
- particle size
- particle lifetime
- particle speed
- gravity strength
- spin and rotation

The mod also includes a **maximum particles per emitter** setting
